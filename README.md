# Asaduzzaman Rocky — Portfolio

Personal portfolio of **Asaduzzaman Rocky**, website designer & developer. I design, build, redesign and fix websites (WordPress, Elementor, WooCommerce and custom React builds) for businesses in the US, UK and Australia.

**Live site:** https://rocky-protfolio.vercel.app

## Tech stack

- [React 19](https://react.dev) + TypeScript
- [Vite 6](https://vitejs.dev)
- [Tailwind CSS 4](https://tailwindcss.com)
- [Motion](https://motion.dev) for animations
- [Formspree](https://formspree.io) for the contact form
- Deployed on [Vercel](https://vercel.com)

## Run locally

Requires Node.js 20 or newer.

```bash
npm install
npm run dev      # http://localhost:3000
```

## Scripts

| Command           | What it does                     |
| ----------------- | -------------------------------- |
| `npm run dev`     | Start the dev server             |
| `npm run build`   | Production build into `dist/`    |
| `npm run preview` | Serve the production build       |
| `npm run lint`    | Type-check the project           |

## Project structure

```
public/            static files (hero video, portrait, icons)
src/
  components/      page sections (Hero, Services, About, Projects, Experience, Contact…)
  data/            portfolio content — projects, experience, skills
  services/        lightweight event tracking
```

To add or edit projects, update `src/data/portfolioData.ts`.
